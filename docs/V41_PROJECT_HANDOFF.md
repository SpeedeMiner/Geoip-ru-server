# GeoIP v41: состояние и незавершённые задачи

> **Открытый сбой аудита:** [v37 run 44026114466](https://github.com/SpeedeMiner/Geoip-ru-server/actions/runs/44026114466) упал на историческом префиксе `31.172.192.0/19` при тайм-ауте RPKI. Сверка ошибочно требует наличия исторического invalid среди актуальных ответов; необходимо разделить состояния и покрыть тестами. Диагностический архив этого прогона отсутствует; условие его сохранения расширено и ожидает проверки в CI. Сетевые ошибки не являются выводами о ROA.


> **Новый контрольный запуск 17 ноября:** [CI v41](https://github.com/SpeedeMiner/Geoip-ru-server/actions/runs/44024510834) прошёл, но свежие входы изменили кандидат: DAT `530b679bd50125c8f1e6b4b49df3bd3285566af9ebf62b1ba15872c28c8e7ed4`, относительно release `63b8abf` +11025/-1536 IPv4 и +713053462628379038341895553024/-0 IPv6; PRIVATE не изменился. Старые сведения ниже о единственной дельте действуют только для прежнего кандидата. Перед решением о публикации разобрать [новую точную дельту](https://github.com/SpeedeMiner/Geoip-ru-server/actions/runs/44024510834/artifacts/14302263202), особенно удаления. Publish пропущен. В [повторном v37 аудите](https://github.com/SpeedeMiner/Geoip-ru-server/actions/runs/44024511205) RDAP 273/273 и IRR 91/91 получили ответы; 3 из 148 RPKI-запросов завершились тайм-аутом; в [следующем независимом запуске](https://github.com/SpeedeMiner/Geoip-ru-server/actions/runs/44025459762) все 148 получили ответы, но один из 273 RDAP-запросов завершился разрывом соединения.


Текущая цель — **RU/BY/KZ + явные DIRECT и WHITELIST + отдельно подтверждённые CDN-адреса**. Чужие категории стран не импортируются. Точные спорные назначения вне региона ждут самостоятельного основания для допуска. BGP, DNS и RDAP не заменяют замер доступности из РФ. Хронология и прошлые решения — в [журнале](V41_EXECUTION_JOURNAL.md).
