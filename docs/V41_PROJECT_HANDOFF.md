# GeoIP v41: состояние и незавершённые задачи

Текущая цель — **RU/BY/KZ + явный DIRECT + отдельно подтверждённые CDN-адреса**. Чужие категории стран не импортируются. Точные спорные назначения вне региона ждут самостоятельного основания для допуска. BGP, DNS и RDAP не заменяют замер доступности из РФ. Хронология и прошлые решения — в [журнале](V41_EXECUTION_JOURNAL.md).

## Состояние передачи

- Основная ветка содержит журнал, но **не содержит** рабочие изменения реализации. Они подготовлены в отдельной ветке передачи; это кандидат, а не выпущенная версия.
- Локальная разработка начата от `c0d2a01ba1fb5f5c0e48965d614945348083a900`. К моменту передачи в main поверх этой базы менялся только журнал. Обновление main следует проверить повторно перед объединением.
- [Последний проверенный Linux CI v41 №349](https://github.com/SpeedeMiner/Geoip-ru-server/actions/runs/43924047898) на исходниках `10833068a021e78602ce3927608ac34c4ceef2f8`: 310 Python-тестов, Go unit tests и сборка прошли. Публикация пропущена. Диагностика BGP дала 9 тайм-аутов и 4 неполных окна без дельты по полученным данным. Подробности и SHA-256 отчётов — в журнале этой ветки.
- [Точная дельта предыдущего кандидата](V41_PR56_DIRECT_DELTA_20261116.json) — историческая. Новый локальный прогон на тех же входах показал +4 096 / −767 IPv4 адресов относительно `63b8abf`; IPv6 и PRIVATE не изменились. Новый Linux CI и домашние сетевые замеры — отдельные проверки.
- Корпоративный реестр и политика содержат по 112 согласованных ASN; 26 ASN входят в контроль потерь, 13 — в диагностическую BGP-сверку. В справочном перечне 11 доменов. Эти числа не означают полноту покрытия.

### 2. Подтвердить маршрутизацию и источники

- [x] Реестр `v41-reviewed-reachable-cdn.tsv` допускает только вручную проверенный одиночный IP с публикацией результата из РФ и привязкой к провайдеру; пока ни одной записи. Hydra WHITELIST справочный, Hydra DIRECT — самостоятельный вклад.

- [ ] Организовать воспроизводимые измерения из подтверждённой домашней сети РФ по точному списку спорных адресов, с IPv4/IPv6 отдельно. Различать IP-блок, SNI/DNS и прикладной отказ; фиксировать источник, дату, метод и срок повторной проверки. Старый [VPNObratno-пилот](https://github.com/SpeedeMiner/Geoip-ru-server/actions/runs/43093976146) подтвердил один RU-выход AS6856, но только 28/30 целей и без подтверждения домашнего типа сети. Он не доказывает доступность новых CIDR.
- [x] Для AS218750 закреплённый ipverse и полное окно RIPE RIS совпали по IPv6-покрытию. У v2fly добавления классифицированы в зарубежных категориях; Hydra DIRECT перекрывает часть IPv4, а не добавляет новый независимый объём. Конкретные сервисы для домашнего измерения пока не установлены.
- [ ] Пополнять `v41-reviewed-unreachable.tsv` только подтверждёнными IP-уровневыми случаями; сейчас реестр пуст. Проверить сохранение регионального и корпоративного ядра и приоритет действующих жёстких исключений. Не делать вывод о доступности или недоступности по одной стране регистрации.
- [ ] Расширить аудит корпоративных и инфраструктурных ASN RU/BY/KZ, включая иностранные аффилированные origin ASN; отдельно проверять принадлежность, роль инфраструктуры и IPv4/IPv6. Не добавлять транзитные и глобальные ASN только из-за соседства или DNS. Для общего хостинга сохранять осторожную классификацию.
- [ ] Расширить и проверить BGP-диагностику на реальных CI-входах. Сопоставлять адресное пространство по семействам, учитывать разные окна ipverse и RIPE RIS, неполные окна и ошибки источника. Расхождения направлять на ручное ревью, а не добавлять маршруты автоматически.
- [x] Рассмотрено расхождение для Kaspi AS35673: [CI-отчёт](https://github.com/SpeedeMiner/Geoip-ru-server/actions/runs/43922390417) показал покрытие `82.115.37.0/24` целиком в DIRECT кандидата. Это не утверждение о покрытии прежнего релиза или доступности из РФ.
- [x] По [повторному BGP-артефакту](https://github.com/SpeedeMiner/Geoip-ru-server/actions/runs/43924047898/artifacts/14256820357) установлены причины отсутствия данных: 9 `TimeoutError`, остальные 4 ASN вернули `partial-window` и нулевую дельту по полученным данным.
- [ ] Добиться воспроизводимости RIPE RIS с ограниченным бюджетом запросов: проверить повтор на закреплённом окне и наблюдать частоту тайм-аутов. Не превращать неполные окна и сетевые ошибки в исчезновение маршрутов.
- [ ] Уточнить актуального пользователя AS43934: запись RIPE содержит историческое название КЦМР, который по [официальному сообщению](https://npck.kz/o-sozdanii-naczionalnoj-platezhnoj-korporaczii-naczionalnogo-banka-respubliki-kazahstan/) реорганизован в 2023 году. Использование этого ASN правопреемником не установлено.
- [ ] Расширить реестр критичных сервисов и проверить источники официальных перечней Минцифры; существующие 11 записей подтверждают домены, а не членство в перечнях, выделенные IP или доступность из РФ. Для сервисов на общем CDN документировать необходимость доменного правила; не выводить широкое IP-исключение из DNS.
