# GeoIP v41: состояние и незавершённые задачи

> **Яндекс DNS из РФ, 17 ноября:** Яндекс Basic через VPNObratno подтверждён по UDP/53 на трёх российских ASN и по DoT/853 на AS50512. В пяти прогонах 10 точечных IPv4 HTTPS-наблюдений успешны, в том числе два новых IPv4 CDNvideo. Оба режима не зависят от ручного домашнего выхода. В 16 DNS-only именах не найдено актуальной сервисной точки внутри шести спорных /24 (0/6). [Отчёт, архивы и дальнейший шаг](V41_YANDEX_VPN_DNS_MEASUREMENTS_20261117.md).

> **Измерения из РФ:** по решению пользователя подтверждённого выхода VPNObratno достаточно, ручной домашний выход больше не требуется. [Два фактических прогона](V41_VPNOBRATNO_CONTROL_MEASUREMENT_20261117.md) подтвердили TCP/TLS и HTTP 200 для четырёх IPv4 двух контрольных CDN-хостов. Это отдельные контрольные цели. Шесть спорных /24 остаются без подтверждённых сервисных IP (0/6).

Точные спорные назначения вне региона ждут самостоятельного основания для допуска. BGP, DNS и RDAP не заменяют замер доступности из РФ. Хронология и прошлые решения — в [журнале](V41_EXECUTION_JOURNAL.md).
