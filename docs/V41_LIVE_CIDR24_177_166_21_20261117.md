## Итог всей очереди

- **6/6 /24** измерены на двух подтверждённых российских ASN в каждом диапазоне. Для **5/6** есть оба постконтроля. Самый ранний диапазон прошёл два предконтроля, постконтроли тогда не записывались.
- В зачтённых сериях **1 536 различных IPv4, 3 072 TCP/443 попытки**, тайм-аут на обоих выходах для каждого IPv4. Ни одного сертификата и **0/6 подтверждённых сервисных пар**. Не включены промежуточные прогоны с непрошедшим постконтролем.
- Это завершение заданного ограниченного TCP-обхода, а не подтверждение блокировки, недоступности всей сети из РФ или отсутствия сервиса. Для решения об обслуживании нужны конкретные имена и адреса, актуальный DNS A и проверенный TLS/SNI и HTTPS.
