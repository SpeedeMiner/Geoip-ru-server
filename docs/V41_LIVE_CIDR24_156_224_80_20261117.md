# v41 — первый фактический замер TCP/443 для одного IPv4 /24

**17 ноября 2026. Подтверждённых сервисных пар по очереди по-прежнему 0/6.** В обоих ограниченных прогонах для одного и того же `156.224.80.0/24` у всех 256 IPv4 TCP/443 не установился до тайм-аута. TLS не начался, сертификатов и имён SAN нет.

Две серии — **512 попыток по 256 разным IP**, не 512 разных IP. Выходы различались по ASN. Сработал исходный контроль Яндекс DNS Basic UDP `77.88.8.8` и закреплённых HTTPS до каждой серии. Один прежний ASN был отклонён на повторе, до этапа /24 на нём не дошло. Ни DNS, ни HTTP к самой подсети не отправлялись. Конкретных имён для сверки через Яндекс DNS не появилось.

[Независимое перечитывание](https://github.com/SpeedeMiner/Geoip-ru-server/actions/runs/44076214711) сверило SHA-256 обоих оригинальных ZIP, CRC и JSON. Все строки входят в объявленный /24, один к одному по IP. 256 пар имеют TIMEOUT|TIMEOUT, ни одна не имеет CONNECTED или сертификата. [Actions 44076214711](https://github.com/SpeedeMiner/Geoip-ru-server/actions/runs/44076214711) · [ZIP 14324169467](https://github.com/SpeedeMiner/Geoip-ru-server/actions/runs/44076214711/artifacts/14324169467).

Лимиты существующего режима — только TCP/443, до 8 одновременных задач, 2,5 с на попытку, до 90 с на сбор и один подтверждённый российский выход на запуск. Отдельные замеры по другим пяти /24 не проводились. Эти два прогона имели здоровый контроль **до** этапа, но ещё не имели постконтроля в том же туннеле. Результат не исключает другие порты, другие сети доступа, сбой в середине измерения, изменение состояния после измерения или другие причины тайм-аута. Не считать тайм-аут доказательством блокировки.

## Постконтроль для следующих запусков

[В режиме v41](https://github.com/SpeedeMiner/Geoip-ru-server/blob/f38fd692c3335cad6a0b0ec001cb7d3e36cc8c89/.github/reachability/CERTIFICATE_CIDR24.md) после этапа добавлены повторная проверка страны и совпадения IP VPN-выхода и один ранее успешный контрольный HTTPS через Яндекс DNS. IP и исходные ошибки в публичный JSON не выводятся. Код возврата ненулевой при непройденном постконтроле, но диагностическое покрытие и строки сохраняются отдельно.

[CI](https://github.com/SpeedeMiner/Geoip-ru-server/actions/runs/44076490773) прошёл — 4 Go-теста, 174 Python-теста. В [интеграционном прогоне](https://github.com/SpeedeMiner/Geoip-ru-server/actions/runs/44076684932) через живой RU VPN AS12494 постконтроль совпадения выхода и HTTPS прошёл через 78 секунд. Collector был подставным и не открывал сокетов, поэтому строки сценария не прибавляются к результату подсети. Это проверяет работу механизма, не восстанавливает задним числом постконтроль двух фактических прогонов.
