# v41 — точечные контрольные замеры через VPNObratno

**Решение пользователя от 17 ноября.** Для текущей проверки доступности достаточно подтверждённого выхода VPNObratno в РФ. Ручной домашний выход исключён из условий. Это одно измерительное место, а не оценка всех российских сетей. Подключение не классифицируется как домашнее.

Два ограниченных прогона исходного `exact_ipv4` запущены из [отдельной диагностической ветки](https://github.com/SpeedeMiner/Geoip-ru-server/tree/diagnostic/v41-vpnobratno-exact-20261117), без изменения PR №5 или выпуска. В каждом подтверждён один выход РФ, оба наблюдения относятся к AS12714. Зафиксированы DNS A/AAAA, точный TCP 443, TLS с проверкой сертификата и SNI, затем HTTP HEAD на `/`. Для CDNvideo это результат по корню хоста, не проверка воспроизведения плеера или конкретного файла.

| Цель | Точный IPv4 | TCP / TLS / HTTP | В RU DAT релиза и кандидата |
|---|---|---|---|
| CDN77 demo, исходный открытый DNS | `84.17.50.24` | подключён / подтверждён / 200 | нет |
| CDNvideo player host, исходный открытый DNS | `88.210.36.192` | подключён / подтверждён / 200 | нет |
| CDN77 demo, A из первого VPN-прогона | `121.127.45.82` | подключён / подтверждён / 200 | нет |
| CDNvideo player host, A из первого VPN-прогона | `151.236.94.32` | подключён / подтверждён / 200 | да |

Первый [прогон](https://github.com/SpeedeMiner/Geoip-ru-server/actions/runs/44049971909) при подключении к заранее закреплённым IP увидел в DNS `121.127.45.82` и `151.236.94.32`. Во [втором прогоне](https://github.com/SpeedeMiner/Geoip-ru-server/actions/runs/44050376976) оба этих IP ответили, но VPN-резолвер уже вернул другие A. Ни в одном из четырёх наблюдений текущий A не совпал с закреплённым IP. Это согласуется со сменой CDN-узлов и не является ошибкой TCP/TLS. AAAA был только DNS-свидетельством, IPv6-транспорт не измерялся.

Сверены GitHub SHA-256 и CRC обоих ZIP: [первый](https://github.com/SpeedeMiner/Geoip-ru-server/actions/runs/44049971909/artifacts/14313915404) и [второй](https://github.com/SpeedeMiner/Geoip-ru-server/actions/runs/44050376976/artifacts/14312888024). [Долговечная копия JSON](v41-vpnobratno-controls-20261117.json) не содержит IP VPN-выходов, профилей или секретов. Проверка членства точек проведена по закреплённым release `63b8abf` (DAT `3dbbffd6…`) и кандидату (DAT `02908f5e…`). Ни один IP не в PRIVATE.

**Область решения.** Метод фактически работает для точечных IPv4. Все четыре адреса вне [очереди шести спорных /24](V41_EXACT_REACHABILITY_ORIGIN_REVIEW_20261117.md), в ней остаётся 0/6 подтверждённых сервисных пар. Замеры не обосновывают допуск всего CDN-префикса или ASN. Правила DIRECT, релиз и CDN не менялись.
